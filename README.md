## 🎮 核心机制与空间循环

- **战场与敌人**：森林林间空地场景，包含 **半兽人战兵（小怪）** 与 **半兽统领·碎颅者格罗姆（BOSS）** 两种敌人。
- **怒气条 → 怒气点（上限 3 点）**：
  - 怒气积蓄槽不可直接使用，通过**贴身剑斩三连击**或**举盾格挡 / 精准弹反**积攒。
  - 每次蓄满 `100%` 自动激活 **1 个怒气点**（上限 3 点）。
- **1 / 2 / 3 怒气点技能（调节远近战斗空间）**：
  - **`1 / Q`【破阵盾冲】（1 怒气点）**：举盾高速突进切入近身，眩晕打断敌军蓄力、重创首领架势，并获得坚毅吸收护盾。
  - **`2 / E`【连锁飞盾】（2 怒气点）**：拉开距离后远距离掷出盾牌，如连锁闪电般**先后飞行撞击附近最多 2 名敌人**并附带减速，随后飞回战士手中。
  - **`3 / R`【怒焰旋风斩】（3 怒气点）**：贴身释放可自由移动的霸体剑刃风暴，多段切割周围群敌并在收招时爆发大范围震击。

## ⌨️ 操作说明

| 按键 | 动作 |
| --- | --- |
| `W A S D` | 移动走位 |
| `鼠标移动` / `滚轮` | 瞄准朝向 / 缩放视角 |
| `鼠标左键` 或 `J` | 近身剑斩三连击（积攒怒气槽） |
| `鼠标右键按住` 或 `K` | 举盾格挡（受击前瞬间按住触发**精准弹反**，获巨量怒气） |
| `空格 Space` 或 `Shift` | 战术垫步闪避 |
| `1 / Q`、`2 / E`、`3 / R` | 释放 1 / 2 / 3 怒气点战技 |
